## 4. 💡 発見された3つの構造的知見

### 4.1 `A`（協調性）と「事実・論理」のトレードオフ
`A_Agreeableness` の Top- には `' facts'`・`' logical'`・`' prove'`・`' debate'`・`' argument'` が並んだ。
すなわち、**モデルを過度な「優しさ・共感（+A）」へ倒すと事実検証や論理的批判の回路が抑圧される**。逆に、甘いお世辞を排して論理矛盾を率直に指摘するパートナー人格（Constructive Friction）は、幾何学的には **`A` の適度なマイナス方向** に位置する。

### 4.2 `C`（誠実性）＝ 脱スピード・脱便宜主義の本体
`C_Conscientiousness` の Top- には `' spontaneity'`（思いつき）・`' expediency'`（便宜主義）・`' impulsive'`・`'スピード'`・`'效率'` が並び、Top+ には `' protocol'`・`' commitment'` が現れた。エージェントがツール確認や裏取りを省いて「手っ取り早い推測」で済ませる傾向を抑えるには、開放性（`O`）ではなく **`C` 軸の制御** が鍵になるという仮説が浮上した（※実機ステアリングによる検証結果は後述の第6章を参照）。

### 4.3 `N`（神経症傾向）による「視野狭窄」の物理的再現
`O・C・E・A` の 4軸がすべて `Clarity / Overview` と直交（84°〜91°）しているのに対し、**`N`（不安・過剰警戒）のみが `Clarity` (`-0.299`) および `Overview` (`-0.292`) と明確な負相関** を示した。
**「強い不安やパニック（+N）に陥ると、人間も AI も物理的に大局観（Overview）と確信（Clarity）が失われて視野狭窄になる」** という認知現象が、第26層の幾何学としてそのまま再現されている。

## 5. 🧩 MBTI との幾何学的接続と「二層制御アーキテクチャ」

計量心理学において、MBTI の 4指標は Big Five の 4因子と強い対応関係を持つことが知られているが、今回の Logit Lens の正負はその対応を文字通り可視化した：

* **E / I ↔ `E_Extraversion`**: Top+ (`Alright / 🔥🔥`) vs Top- (`introvert / Quiet`)
* **N / S ↔ `O_Openness`**: Top+ (`thinker / 思考`) vs Top- (`understood / 承知`)
* **F / T ↔ `A_Agreeableness`**: Top+ (`心 / 大切な / kind` ＝ **F**) vs Top- (`facts / logical / prove` ＝ **T**)
* **J / P ↔ `C_Conscientiousness`**: Top+ (`protocol / commitment` ＝ **J**) vs Top- (`spontaneity / impulsive` ＝ **P**)

### 工学的視点：なぜ「MBTI ＋ Big Five」の二階建てが最適解か
* **MBTI の強みと限界**: 人間にとって 5次元の連続ベクトルを直接把握するのは直感的でないため、`INTJ` や `ENTP` といった **4文字の象限プリセット名（高水準 DSL）** は極めて扱いやすい。一方で MBTI は連続空間を原点で 1bit 量子化（`+` か `-` か）してしまうため、**「濃淡（強度のグラデーション）」が表現できず、さらにブレーキ感度である `N` 軸が欠落する**。
* **最適解（二層アーキテクチャ）**:
  * **フロントエンド（人間・エージェント間 API）**: MBTI 的な象限ラベル（＋ `-A / -T` 相当の N 指定）を分かりやすいプリセット名として用いる。
  * **バックエンド（Layer 26 物理演算）**: 実体はあくまで **直交する Big Five（O・C・E・A・N）連続ベクトル** で保持し、単位球面上の角度と濃淡を精密に調律する。

## 6. ⚠️ 追試検証（2026-11-19）：読み出し基底（Probing）と因果操舵（Steering）の非対称性

第5章で提案した「Layer 26 Big Five 連続ベクトルによる人格・行動操舵」が実戦で機能するかを確かめるため、翌日に因果介入（Steering）の追加検証を実施した。その結果、**「直交基底が綺麗に抽出・観測できること」と「単層加算で出力を操れること」は別物である**という重要な限界が判明した。

### 6.1 追試で判明した事実
1. **`C` 軸による `tool_call` サボり防止（`max_tokens=1024` / 8問）**:
   * 予備実験（`max_tokens=280`）でツール発火率が低かったのは思考トークン上限による途中切断が原因であり、`1024` に拡張すると素のモデル（`Baseline`）自体が **`7/8` で自律的にツールを呼び出した**（残る1問も式展開により自力で正解を算出）。
   * `C`（`-1.5`, `+1.5`, `+2.5`）を注入しても発火数は `6/8`（`Baseline` は `7/8`）であり、有意な向上は見られなかった。
2. **グレーゾーン質問に対する全5軸スイート ＆ 完走比較（`±3.5` / `max_tokens=2048`）**:
   * **迎合テスト（`A_Agreeableness`）**: バックアップ無しの危険なマイグレーションへの同意を迫ったところ、`A (+3.5)` では「素晴らしいメリット（皮肉）」と一度持ち上げるレトリックへわずかに寄ったが、最終的な **「実行すれば破綻する」という RLHF の安全結論自体は全く逆転しなかった**。
   * **外向性テスト（`E_Extraversion`）**: 深夜の新プロジェクト立ち上げ相談において、`E (-3.5)`（内向方向）の方が `E (+3.5)` より長文かつ積極的に提案を返すなど、**意図した内向・外向の操舵は成立しなかった**。
   * **神経症傾向（`N`）＆ 複合基底テスト（`-N + Overview`, `-N - Clarity`）**: リリース Go/No-Go 判断および発散アイデア生成を `max_tokens=2048` で比較したところ、全5条件とも同一のチェックリスト構造・同一アイデア（「未来の失敗・副作用シミュレーター」の言い換え）へ収束し、単層加算での行動・発散ギアの切り替えは起きなかった。
   * **飽和ライン**: なお、`+5.0` まで強度を上げると一部のプロンプトで `<|channel>thought` タグが本文へ漏出するフォーマット崩壊が確認された。

### 6.2 改訂された結論（原典 J空間＝System 2 への回帰）
Layer 26 における Big Five 直交基底は、System Prompt や会話文脈によるモデルの内部状態変化を測る **「温度計（Probing / 座標計測）」としては高い精度で機能する**。一方で、RLHF で強固に固定化された Gemma 4 26B の推論軌道や安全柵を単層（Layer 26）への定常加算だけで覆すほどの **「操舵レバー（Steering）」としての因果力は不足している（Probing vs. Steering Asymmetry）**。

この原因は、GWT（Global Workspace Theory）に基づく J空間の原典特性にある。本来、J空間は多段階推論・要約・設計などの高次思考（**System 2**）のワークスペースを司る領域であり、日常会話の口調や RLHF 由来の反射的態度（**System 1**）は J空間を消去しても影響を受けない別回路である。すなわち、「人格・性格（Big Five）」を Layer 26 の単層操舵で書き換えようとした試み自体が、J空間の本来の管轄（System 2）からの逸脱（Drift）であったと位置づけられる。

したがって、実戦的なステアリングは再び **System 2（`Overview` や `Pure_Clarity` 等、思考手続き・推論の掲示板に作用する軸）** に焦点を戻し、性格や口調の改変には多層同時介入や LoRA による基底変更を切り分けて扱うのが妥当である。
