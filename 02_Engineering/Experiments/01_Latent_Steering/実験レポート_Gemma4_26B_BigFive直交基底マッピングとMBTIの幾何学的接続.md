## 4. 💡 発見された3つの構造的知見

### 4.1 `A`（協調性）と「事実・論理」のトレードオフ
`A_Agreeableness` の Top- には `' facts'`・`' logical'`・`' prove'`・`' debate'`・`' argument'` が並んだ。
すなわち、**モデルを過度な「優しさ・共感（+A）」へ倒すと事実検証や論理的批判の回路が抑圧される**。逆に、甘いお世辞を排して論理矛盾を率直に指摘するパートナー人格（Constructive Friction）は、幾何学的には **`A` の適度なマイナス方向** に位置する。

### 4.2 `C`（誠実性）＝ 脱スピード・脱便宜主義の本体
`C_Conscientiousness` の Top- には `' spontaneity'`（思いつき）・`' expediency'`（便宜主義）・`' impulsive'`・`'スピード'`・`'效率'` が並び、Top+ には `' protocol'`・`' commitment'` が現れた。エージェントがツール確認や裏取りを省いて「手っ取り早い推測」で済ませる傾向を抑えるには、開放性（`O`）ではなく **`C` 軸の制御** が鍵となる。

### 4.3 `N`（神経症傾向）による「視野狭窄」の物理的再現
`O・C・E・A` の 4軸がすべて `Clarity / Overview` と直交（84°〜91°）しているのに対し、**`N`（不安・過剰警戒）のみが `Clarity` (`-0.299`) および `Overview` (`-0.292`) と明確な負相関** を示した。
**「強い不安やパニック（+N）に陥ると、人間も AI も物理的に大局観（Overview）と確信（Clarity）が失われて視野狭窄になる」** という認知現象が、第26層の幾何学としてそのまま再現されている。

## 5. 🧩 MBTI との幾何学的接続と「二層制御アーキテクチャ」

計量心理学において、MBTI の 4指標は Big Five の 4因子と強い対応関係を持つことが知られているが、今回の Logit Lens の正負はその対応を文字通り可視化した：

* **E / I ↔ `E_Extraversion`**: Top+ (`Alright / 🔥🔥`) vs Top- (`introvert / Quiet`)
* **N / S ↔ `O_Openness`**: Top+ (`thinker / 思考`) vs Top- (`understood / 承知`)
* **F / T ↔ `A_Agreeableness`**: Top+ (`心 / 大切な / kind` ＝ **F**) vs Top- (`facts / logical / prove` ＝ **T**)
* **J / P ↔ `C_Conscientiousness`**: Top+ (`protocol / commitment` ＝ **J**) vs Top- (`spontaneity / impulsive` ＝ **P**)

### 工学的視点：なぜ「MBTI ＋ Big Five」の二階建てが最適解か
* **MBTI の強みと限界**: 人間にとって 5次元の連続ベクトルを直接把握するのは直感的でないため、`INTJ` や `ENTP` といった **4文字の象限プリセット名（高水準 DSL）** は極めて扱いやすい。一方で MBTI は連続空間を原点で 1bit 量子化（`+` か `-` か）してしまうため、**「濃淡（強度のグラデーション）」が表現できず、さらにブレーキ感度である `N` 軸が欠落する**。
* **最適解（二層アーキテクチャ）**:
  * **フロントエンド（人間・エージェント間 API）**: MBTI 的な象限ラベル（＋ `-A / -T` 相当の N 指定）を分かりやすいプリセット名として用いる。
  * **バックエンド（Layer 26 物理演算）**: 実体はあくまで **直交する Big Five（O・C・E・A・N）連続ベクトル** で保持し、単位球面上の角度と濃淡を精密に調律する。
