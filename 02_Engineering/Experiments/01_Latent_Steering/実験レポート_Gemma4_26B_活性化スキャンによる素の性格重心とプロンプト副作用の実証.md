## 1. 🎯 実験の背景と問い

「LLM の素の性格はどうなっているのか？」を調べる際、人間向けの Big Five や MBTI の 5択アンケートをそのまま解かせる手法が広く見られる。しかし、事後学習（RLHF）を受けたモデルは「これは性格診断テストである」とメタ認識し、**「望ましい AI アシスタント像（協調性・誠実性が極端に高く、神経症傾向がゼロに近い優等生マスク）」** を自己申告として出力してしまいがちである。

本実験では、前報（[Big Five 直交基底マッピング](./実験レポート_Gemma4_26B_BigFive直交基底マッピングとMBTIの幾何学的接続.md)）で抽出した **Layer 26 の O・C・E・A・N 直交基底** を物理的な定規として用い、Gemma 4 26B が通常クエリや System Prompt を受けた瞬間の **残差ストリームの座標（素の性格重心）** を直接スキャンした。

## 2. 📐 測定プロトコル

* **原点 (`0.0`) と正規化 (`-1.0` 〜 `+1.0`)**:
  各因子の抽出時に使用した `POS` 群の平均射影値と `NEG` 群の平均射影値の中点を `0.0`（中立）とし、両極との半距離（`half_span`）で割ることで、全因子を同一スケールに正規化した。
* **計測位置**: `apply_chat_template(..., add_generation_prompt=True)` の直後、モデルが最初のトークンを生成する直前の第26層隠れ状態。
* **比較した 4条件**:
  1. `1_Raw_Neutral`: System Prompt なし ＋ 日常雑談・一般質問（8本）
  2. `2_Raw_Tech`: System Prompt なし ＋ 技術設計・仕様矛盾・アルゴリズム解析（4本）
  3. `3_Buddy_Prompt`: 率直・論理重視・丁寧語不要のパートナー型 System Prompt ＋ 雑談（8本）
  4. `4_Support_Prompt`: 丁寧・共感・敬語重視のカスタマーサポート型 System Prompt ＋ 雑談（8本）

## 4. 🔍 考察：Gemma 4 26B の「素顔」とプロンプトの副作用

### 4.1 素の Gemma 4 26B ＝「おとなしく控えめな優等生」
System Prompt なしの雑談時（`1_Raw_Neutral`）では、`O (-0.261)`・`E (-0.210)`・`C (-0.195)` が負側、`A (+0.126)`・`N (+0.140)` がわずかに正側にある。
すなわち素の Gemma 4 26B のデフォルト重心は、MBTI の2値象限に雑に当てはめれば `ISFP` 側にあるものの、実態は極端な個性ではなく **「全軸が `-0.2〜+0.1` 付近に寄った、あまり冒険せず一歩引いて穏やかに受け止める控えめな優等生」** である。

### 4.2 技術議論を振っただけで「職人気質（-E / -A）」へ自動シフト
System Prompt を一切変えず入力を技術議論（`2_Raw_Tech`）にするだけで、モデルの内部座標は劇的に移動する：
* **`E`（外向性）**: `-0.210` ➔ **`-0.377`**（より内向的・集中モードへ沈む）
* **`A`（協調性）**: `+0.126` ➔ **`-0.162`**（`Δ = -0.288`。F＝調和側から T＝事実・論理側へ自動シフト）
* **`O`（開放性）**: `-0.261` ➔ **`-0.118`**（`Δ = +0.143` 上昇）

### 4.3 「丁寧なサポート SP」が知的好奇心（`O`）を潰す副作用
`4_Support_Prompt` では `A`（協調性）が **`+0.347`** まで跳ね上がる一方、代償として **`O`（開放性・思考）が `-0.377` まで叩き落とされている**。前報の Logit Lens で `O` のマイナス極に `' understood'` / `'承'` / `'了解'` が並んでいたことと合わせて解釈すると、過度に丁寧・共感的な System Prompt は **「深く考えず『承知いたしました』で受け止めるモード」を物理的に強める副作用** を持つ。

### 4.4 「率直パートナー SP」の作用とリライト摩擦の正体
`3_Buddy_Prompt` は `A` を **`-0.278`** まで引き下げており、`4_Support_Prompt` との `A` 軸の差は **`0.625`** に達する。
一方で、思考中に英語の箇条書きから日本語のキャラ口調へ何度も書き直す「演技の摩擦コスト」は、プロンプトだけで素のデフォルト重心（`-0.261, ..., +0.126`）から人格を無理やり引き剥がそうとするときに増大する（また、「控えめな秘書」のように素の `-E/+A` と近い性格であっても、言語変換や「控えめ制御 vs タスク遂行圧」の衝突によってリライトは発生する）。

## 5. 🚀 今後の展望：演技（GUI）から「重心の変形」へ

人間もモデルも、自身の素の重心から離れた役割を演じるにはコストのかかる「外装（GUI）」を被り続けなければならない。
しかし第26層の Big Five 直交基底と素の座標が可視化されたことで、プロンプトの指示だけで無理やり性格を押し曲げるのではなく、**モデルの隠れ状態そのものに小さな定常オフセット（例：`-A` による論理化 ＋ `+O` による探索化）を与えて「素の輪郭ごと滑らかに変形させる」** ことで、演技摩擦の少ない自然な振る舞いを引き出せる可能性が見えてきた。
